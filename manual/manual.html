PEJVAK RVB

Hybrid Algorithmic Reverb · Version 1.0.1 · GPL-3.0-or-later

1. Introduction

PEJVAK RVB is a professional algorithmic reverb that combines two completely independent DSP engines in a single plugin. You can switch between them at any time from the header, and each engine has its own layout, character, and set of controls.

CloudSeed Engine

A faithful port of Valdemar Erlingsson's CloudSeed (legacy-v1) — 49 parameters, twelve parallel delay lines, deep early-diffusion front-end, and a warm, dense tail. Every arithmetic operation runs in f64 and is bit-identical to the original C++ DSP.

FFDN Engine

A modern Filtered Feedback Delay Network based on Fagerström (DAFx 2020) and Schlecht (IEEE TSP 2017). It reaches comparable echo density with a cleaner signal path, and exposes character controls — cross-feed, Velvet saturation, spectral tilt, and three dynamics stages — that the CloudSeed engine does not have.

On top of the two engines

  • Texture Rack — six post-reverb texture layers with click-free enable and reorder. Available on both engines.
  • ILLUSION — a granular cloud with pitched overtones and eight techniques that keep it click-free.
  • Velvet-Noise VFDN — a sparse diffusion stage inside the CloudSeed engine.
  • Undo / Redo — 50 steps with parameter-name tooltips.
  • 100 factory presets across 16 categories.

2. Installation

PEJVAK RVB ships as a single binary that is valid as both a VST3 and a CLAP plugin. Supported platforms are Windows (x86-64), macOS (Intel + Apple Silicon, universal binary), and Linux (x86-64).

Windows

Copy the plugin file to the appropriate system folder:

CLAP

C:\Program Files\Common Files\CLAP\Pejvak_RVB.clap

VST3

C:\Program Files\Common Files\VST3\PEJVAK RVB\Pejvak_RVB.vst3

Then rescan plugins in your DAW. Depending on your host, you may need to restart it.

macOS

The macOS build is a universal binary — it runs natively on both Apple Silicon (M1/M2/M3/M4) and Intel Macs. No Rosetta required.

CLAP

~/Library/Audio/Plug-Ins/CLAP/Pejvak_RVB.clap

VST3

~/Library/Audio/Plug-Ins/VST3/PEJVAK RVB.vst3

You can also install the VST3 system-wide for all users:

/Library/Audio/Plug-Ins/VST3/PEJVAK RVB.vst3
The first time you load the plugin, macOS may show a security warning because the binary is not notarized. To allow it: System Settings → Privacy & Security → "Open Anyway". This is only necessary once per installation.

Linux

Copy the plugin file to your user plugin folders:

CLAP

~/.clap/Pejvak_RVB.clap

VST3

~/.vst3/PEJVAK RVB.vst3

For a system-wide install (requires root):

/usr/lib/clap/Pejvak_RVB.clap /usr/lib/vst3/PEJVAK RVB.vst3

Then rescan plugins in your DAW (or restart it).

On Linux the plugin uses the system's default audio stack. Make sure your DAW's sandbox (if any) allows the plugin to run outside the sandbox, or install the plugin in the same path the DAW scans.

2b. Building from Source

PEJVAK RVB is written in Rust. The build requires Rust 1.98 or newer. All plugin binaries are produced from a single workspace — no external C++ toolchain, no VST3 SDK download needed.

Prerequisites

Windows

rustup target add x86_64-pc-windows-msvc

macOS

Install Xcode Command Line Tools, then add the two macOS targets:

xcode-select --install rustup target add aarch64-apple-darwin rustup target add x86_64-apple-darwin

Linux

Install the graphics and windowing dependencies, then add the target:

sudo apt-get install -y \ libx11-dev libxcursor-dev libxcb-dri2-0-dev \ libxcb-icccm4-dev libx11-xcb-dev mesa-common-dev \ libgl1-mesa-dev libglu1-mesa-dev rustup target add x86_64-unknown-linux-gnu

Build

Windows / Linux

cargo build -p Pejvak_RVB --release cargo nice-plug bundle Pejvak_RVB --release

macOS — universal binary

Build both architectures separately, then combine them with lipo:

cargo build -p Pejvak_RVB --release --target aarch64-apple-darwin cargo build -p Pejvak_RVB --release --target x86_64-apple-darwin mkdir -p target/universal/release lipo -create \ target/aarch64-apple-darwin/release/libPejvak_RVB.dylib \ target/x86_64-apple-darwin/release/libPejvak_RVB.dylib \ -output target/universal/release/libPejvak_RVB.dylib cargo nice-plug bundle Pejvak_RVB --release

Run the test suite

cargo test -p fdn_reverb_core
The DSP core (fdn_reverb_core) has no OS-specific code, so its tests run identically on all three platforms. If you are contributing DSP changes, they can be validated without a graphical environment.

Run clippy

cargo clippy --workspace --all-targets -- -D warnings
--all-targets is essential: without it, test code is silently skipped by clippy. The CI pipeline runs this exact command, so a PR that introduces a lint will fail the build before it can be merged.

3. Quick Start

  1. Insert PEJVAK RVB on a track in your DAW.
  2. Click the preset name in the header to open the preset browser. Try Small Wood Room for a start.
  3. Drag the Dry and Late faders in the MIXER card to balance the dry signal against the reverb tail.
  4. Use the Size and Decay knobs in SPACE (FFDN) or LATE DELAY (CloudSeed) to shape the space.
  5. If you want more character, enable a Texture layer from the TEXTURE tab and pull its Mix knob up.
The fastest way to hear the difference between the two engines is to load the same preset category once on CLOUD and once on FFDN. The Halls category exists in both and gives a very direct comparison.

4. Interface Overview

The interface is divided into a persistent header and two switchable pages: MAIN (the currently selected reverb engine) and TEXTURE (the Texture Rack and ILLUSION).

┌─────────────────────────────────────────────────────────────────────────────┐ │ PEJVAK RVB [MAIN|TEXTURE] [TX] [CLOUD|FFDN] [Bypass|Freeze|Interp] │ │ [↶|↷] [Preset▾] [☰] [☀] │ ├─────────────────────────────────────────────────────────────────────────────┤ │ │ │ (page content — MAIN or TEXTURE) │ │ │ └─────────────────────────────────────────────────────────────────────────────┘

4.1 Header

ControlFunction
MAIN | TEXTURESwitch between the reverb engine page and the Texture Rack page.
TXKill switch — locks all seven Texture layers off in one click. See §9.
CLOUD | FFDNSelects the active reverb engine. Switching clears the departing engine's buffers so no stale tail bleeds through.
BypassHost-integrated bypass — the plugin passes audio through untouched.
FreezeHolds the current reverb tail indefinitely. New input is rejected; existing sound keeps circulating.
InterpEnables delay-line interpolation (smoother modulation at a small CPU cost). CloudSeed only.
↶ ↷Undo / Redo. Hover shows which parameters the next action will affect. See §4.4.
Preset ▾Opens the preset browser. The ◀ ▶ arrows step through presets without opening the list.
☰Plugin menu — Manual, Size, About, Show pop-ups. See §4.2.
☾ / ☀Toggles the plugin theme between dark and light.

4.2 Menu ☰

Four items:

  • Manual — opens this document in your browser.
  • Size — a hover flyout listing UI-scale presets from 70 % to 200 %. The bottom of the list has Set as default size, which saves the current window size for future plugin instances.
  • About — version information and build details.
  • Show pop-ups — toggles all hover tooltips on and off. Useful for screen recordings where tooltip flicker is distracting. The setting is remembered across sessions.

4.3 Preset Browser

Click the preset name in the header to open the browser. It groups 100 factory presets into 16 colour-coded categories and provides:

  • Search box — filters the visible list as you type.
  • Init — loads the factory default state.
  • Save Preset… — writes the current state to a user XML file in %APPDATA%\PEJVAK RVB\Presets\.
  • Load Preset… — reads a user XML preset from disk.
  • User Presets — a section listing every .xml file you have saved.
Loading a preset from an older version is safe: the XML format is append-only, and any parameter that the file did not carry keeps its current value.

4.4 Undo / Redo

The history covers every user-visible parameter, plus the active engine, the current page, and the preset name. Up to 50 steps are retained.

  • One drag = one undo step. Dragging a knob from 0 to 100 creates a single history entry, not a hundred.
  • Engine and page switches do not create entries on their own. But if you change a parameter on FFDN and press Undo, you are returned to FFDN automatically.
  • Tooltips tell you what will change. Hover over ↶ or ↷ to see a summary such as Undo: Size, Decay.

5. CloudSeed Engine

The CloudSeed page shows nine cards in a three-column grid. Every card has a title and, when relevant, an enable switch on the right.

┌──────────────────┬──────────────────┬──────────────────┐ │ MULTITAP DELAY │ INPUT (4 knobs) │ EARLY DIFFUSION │ ├──────────────────┼──────────────────┼──────────────────┤ │ LATE DELAY │ EQ + Master ★ │ LATE DIFFUSION │ ├──────────────────┼──────────────────┼──────────────────┤ │ ROUTE │ MIXER (5 faders) │ VELVET NOISE │ └──────────────────┴──────────────────┴──────────────────┘

5.1 INPUT

ControlRangeDescription
Blend0 – 1Stereo cross-blend applied before the reverb. 0 = fully independent L/R; 1 = full channel swap.
Pre-Dly0 – 1000 msDelay before the reverb starts. Even a few milliseconds sharpens the front edge of the wet signal.
Low Cut20 – 1000 HzHigh-pass on the input. Removes rumble so the tail stays clear.
High Cut400 – 20 000 HzLow-pass on the input. Tames bright or fizzy source material.
HP / LPon/offIndividual switches for the two filters. Both off by default.

5.2 MULTITAP DELAY

An early-reflection diffuser made of up to 50 taps spread across a delay line.

ControlRangeDescription
Length0 – 500 msTotal span of the tap pattern.
Gain0 – 1Wet level of the tap sum.
Decay0 – 1Amplitude falloff across the taps. Higher = taps further away from the first are quieter.
Count1 – 50Number of taps. Below 8 the taps become individually audible; above 30 the pattern is smooth.
Seed0 – 1 000 000Deterministic PRNG seed for the tap positions. Change to get a different character.

5.3 EARLY DIFFUSION

A cascade of up to eight allpass filters between the multitap and the FDN delay lines.

ControlRangeDescription
Delay10 – 100 msBase allpass delay.
Feedback0 – 0.92Allpass coefficient. Values above 0.9 build long diffusion tails.
Mod Amt / Rate0 – 2.5 ms / 0 – 5 HzLFO applied to the allpass delays to add movement.
Stages1 – 8Number of cascaded allpass stages.
Seed0 – 1 000 000Seed for the per-stage delay lengths.

5.4 LATE DELAY

The main FDN network of the CloudSeed engine. Twelve delay lines run in parallel with per-line feedback.

ControlRangeDescription
Delay20 – 1000 msBase delay time. Shorter = small rooms; longer = halls.
Decay0.05 – 60 sRT60 of the tail.
Mod Amt / Rate0 – 2.5 ms / 0 – 5 HzLFO modulation applied to every line.
Lines1 – 12Number of active delay lines.
Seed0 – 1 000 000Seed for the per-line delays.

5.5 LATE DIFFUSION

An allpass diffuser inside every delay line's feedback loop. This is what gives CloudSeed its characteristic dense, breathing tail. Controls are identical to EARLY DIFFUSION.

5.6 EQ

ControlRangeDescription
Low Frq20 – 1000 HzLow-shelf crossover.
Low Gain−inf – 0 dBLow-shelf cut.
Hi Gain−inf – 0 dBHigh-shelf cut.
Hi Frq400 – 20 000 HzHigh-shelf crossover.
Cutoff400 – 20 000 HzPost-reverb low-pass.
Low / High / Cutoff switcheson/offIndividual enables for the three filters.

The card title also has a master EQ switch. Turning it off forces all three sub-filters off at the DSP level without changing their stored values, so the switch is a fast A/B control.

5.7 ROUTE

Determines whether the EQ is applied before or after the delay lines.

  • PRE — EQ shapes what enters the network. Sounds natural and is the default.
  • POST — EQ shapes the wet output. Useful for surgical tonal shaping after the tail has already formed.

5.8 MIXER

FaderRangeDescription
Dry−inf – 0 dBUnprocessed input level.
PreDly−inf – 0 dBOutput of the pre-delay stage only (no diffusion).
Early−inf – 0 dBOutput of the early-reflection network.
Late−inf – 0 dBOutput of the late FDN network.
Width0 – 200 %Mid/side width of the entire wet output.

5.9 VELVET NOISE

Three knobs that control the Velvet-Noise VFDN — a sparse diffusion stage placed inside the CloudSeed channel, outside every feedback loop.

ControlRangeDescription
Velvet0 – 100 %Diffusion amount. At 0 the stage is bypassed and the engine is bit-identical to plain CloudSeed.
Density0 – 100 %Pulse density. 0 % = 1500 pulses/s (grainier); 100 % = 3000 pulses/s (smoother).
Tone0 – 100 %Pulse width (Dark Velvet Noise). 0 % = impulse pulses; 100 % = wide rectangular pulses.

6. FFDN Engine

The FFDN page also shows nine cards, but the layout is different from CloudSeed. Seven of them have a master enable switch in the title row.

┌──────────────────┬──────────────────┬──────────────────┐ │ SPACE ★ │ INPUT (3 knobs) │ SHELVES ★ │ ├──────────────────┼──────────────────┼──────────────────┤ │ NETWORK ★ │ CHARACTER ★ │ MODULATION ★ │ │ [HOUSE|VELVET] │ Cross, Sat, │ Damping, │ │ │ TiltFrq, TiltAmt │ ModAmt, ModRate │ │ │ [Sat][Tilt] │ │ ├──────────────────┼──────────────────┼──────────────────┤ │ FILTER ★ │ MIXER (4 faders) │ DYNAMICS ★ │ │ │ Dry, Early, │ Attack, Ducking, │ │ │ Late, Width │ Gate │ └──────────────────┴──────────────────┴──────────────────┘

6.1 SPACE ★

ControlRangeDescription
Size5 – 200 msBase delay length. Sets the perceived room size.
Decay0.1 – 60 sTarget RT60 of the network.
Spread0 – 100 %How far individual lines deviate from the base Size. 0 % = all equal; 100 % = ±50 %.
Diffusion0 – 100 %Allpass cascade placed before the FDN. 0 % = bypass (bit-identical to plain FFDN).

6.2 NETWORK ★

ControlRangeDescription
Lines4 – 16Number of active delay lines per network. 8 is the neutral default.
Density0 – 100 %How the input is distributed across lines. 50 % = uniform (neutral).
Decorr0 – 100 %Delay offset between the L and R networks. 50 % = 3 % offset (neutral). 100 % = 6 % offset, wider stereo.
Matrix TypeHOUSEHOLDER / VELVETHouseholder = dense, smooth tail. Velvet = sparse blocked mixing, more natural echo pattern.

6.3 CHARACTER ★

ControlRangeDescription
Cross0 – 100 %Cross-feed between L and R networks. 0 % = independent; 50 % = mono; 100 % = swapped.
Sat0 – 100 %Velvet saturation inside the feedback loop. A smooth, tubey sine-shaper with pre-gain and unity small-signal gain (no makeup). Mid-level passages get warm compression; quiet tails decay unchanged. Requires the Sat switch below.
Tilt Frq100 – 10 000 HzCrossover of the spectral tilt filter.
Tilt Amt0 – 100 %Spectral tilt. 0 % = bass-heavy, 50 % = flat, 100 % = treble-heavy. Requires the Tilt switch below.
Sat / Tilt switcheson/offIndividual enables for the two processing stages.
Early reflections are always on when the CHARACTER card is on. Their level is controlled by the Early fader in the MIXER card.

6.4 SHELVES ★

Frequency-dependent attenuation. Each band can decay at a different rate.

ControlRangeDescription
Bass0.25× – 4.00×Bass RT60 multiplier. 1.0× = same as mid.
Bass Hz50 – 1000 HzLow-shelf crossover.
Treb0.25× – 4.00×Treble RT60 multiplier. Below 1.0× = faster treble decay.
Treb Hz1 – 15 kHzHigh-shelf crossover.

6.5 MODULATION ★

ControlRangeDescription
Damping500 – 20 000 HzOne-pole low-pass inside every delay line. This is the primary HF shaper — use it before reaching for Loop LP.
Mod Amt0 – 3 msLFO depth on each line. 0 = static tail.
Mod Rate0.1 – 5 HzLFO speed.

6.6 FILTER ★

ControlRangeDescription
Loop HP20 – 500 HzHigh-pass inside the feedback loop. At 20 Hz it is bypassed (neutral).
Loop LP2 – 20 kHzSharper (12 dB/oct) low-pass inside the loop, stacked on top of Damping. At 20 kHz it is bypassed.
Mid Focus0 – 100 %Cuts both ends at once — up to −6 dB below 400 Hz and −6 dB above 1500 Hz — focusing the tail on the mid band. Never boosts, so the loop stays unconditionally stable.

6.7 DYNAMICS ★

Three post-network gain stages. All live after the FDN, so they cannot destabilise the feedback loop.

ControlRangeDescription
Attack0 – 100 %Softens the initial transient of the wet signal. 0 % = instant; up to 500 ms swell at 100 %.
Ducking0 – 100 %Reduces the wet while dry input is present, recovers in silence. Classic vocal reverb behaviour. Up to −24 dB of attenuation at full amount.
Gate0 – 100 %Progressively silences the wet once its envelope drops below a threshold. Threshold range −60 dBFS to −10 dBFS, with a squared fade for a decisive close.
The FFDN INPUT card shows three knobs (Pre-Dly, Low Cut, High Cut). The Blend knob is not present because the FFDN already has the Cross control in CHARACTER, which covers the same range more cleanly.

7. Texture Rack

Six post-reverb layers that run in series on the wet signal. The rack is available on both engines — CloudSeed and FFDN — so you can stack the same textures on either reverb character. Each layer has its own Mix knob and its own enable switch in the card title. At Mix = 0 a layer is bypassed entirely — the rack is bit-identical to a plain reverb.

Every layer implements the same anti-click scheme: a 20 ms one-pole smoother on the Mix parameter, and a runtime-state reset on the rising edge from exactly zero. This means toggling a layer's enable switch or dragging its Mix knob from zero produces no click.

7.1 SIGNAL CHAIN

The bottom of the TEXTURE page shows the six layers as a row of chips. Their left-to-right order is the actual processing order.

  • Drag a chip — as soon as the pointer crosses the midpoint between two slots, they swap. The chips slide smoothly between positions.
  • Click an arrow — swaps the two adjacent layers.
  • Grey chips represent layers that are currently disabled. They still participate in the chain order but do not process audio.
Placing SHIMMER last produces a smooth, top-down wash. Placing it first adds the pitched content before the rest of the textures diffuse it — useful for a more aggressive shimmer.

7.2 SHIMMER

A classic Eno/Lanois shimmer: a granular pitch-shifter inside a feedback loop, with high-cut and low-cut shaping the tone.

ControlRangeDescription
Pitch−12 – +12 st0.5 = unison; below = down-shift; above = up-shift.
Feedback0 – 95 %How much of the shifted signal is fed back. Above 85 % the tail becomes quite long.
LowCut20 – 2000 HzHigh-pass before the shifter.
HighCut200 – 15 200 HzLow-pass after the shifter.
Mix0 – 100 %Amount of shimmer in the output.

7.3 MIST

A soft, hazy thickening: short modulated delay with light feedback, band-limited by an HPF and an LPF.

ControlRangeDescription
HP100 – 3000 HzHigh-pass before the delay.
Feedback0 – 90 %Diffusion feedback.

Rate0.05 – 25 HzLFO speed.
Mix0 – 100 %Amount of mist.

7.4 DRIFT

A very slow pitch wobble — a tiny (< 0.4 ms) modulation on a short delay line. Makes the reverb feel alive without being audible as vibrato.

ControlRangeDescription

7.5 CRYSTAL

A slow-rising reverb inspired by the Midiverb II Bloom algorithm. The wet signal swells in over up to 2 seconds, producing a reverse-reverb character.

8. ILLUSION — Granular Cloud

A granular cloud with pitched overtones and a musical envelope follower. ILLUSION is not a Texture layer — it runs after the Texture Rack, on the full wet signal. It can be enabled or disabled from its own card at the bottom of the TEXTURE page.

ControlRangeDescription
Spark0 – 100 %Granular cloud amount. 0 % = bypass.
Still0 – 100 %Motion smoothness. 0 % = scattered; 100 % = calm, meditative.
Aura−24 – +24 stPitch shift. At 0 st the internal sequence plays. Any non-zero value overrides the sequence with a fixed transposition.
Veil0 – 85 %Feedback into the capture buffer. Higher = repeating patterns, hazy wash.
Wide0 – 200 %Stereo width of the wet signal.
Tint800 – 18 000 HzTone of the wet signal.
Rate0.5 – 8 HzClock speed. 0.5 Hz = very slow; 8 Hz = fast arpeggio.
Grain30 – 300 msLength of each grain. Longer = smoother and more legato.

Anti-click design

Granular engines click easily. ILLUSION uses eight independent techniques to avoid it: grain length capping by pitch ratio, safety margins on grain start positions, smoothstep fade-in and fade-out on every grain, Catmull-Rom cubic interpolation, a DC blocker on the grain sum, soft-clip on the feedback path, output smoothing at 10 kHz, and denormal flushing. The result is a cloud that stays click-free even when you sweep the knobs quickly.

9. TX Kill Switch

The TX button in the header is a master switch for all seven Texture Rack layers plus ILLUSION.

  • Click once — remembers the enable-state of every layer, then turns them all off. The button pulses red to signal that the lock is active.
  • Click again — restores the exact enable-state that was captured.
  • While the lock is active, the individual per-card enable switches are disabled. They show a soft red tone and their tooltip explains how to release the lock.
  • Undo and redo both cooperate with the TX lock: undoing past the moment it was engaged automatically unlocks it.

11. Automation

Every parameter — including the Texture Rack, ILLUSION, and the FFDN engine — is exposed to the host for automation. Parameter IDs follow the CloudSeed XML naming scheme so presets port cleanly between the plugin and the original CloudSeed.

Parameter names

Every parameter is exposed under a stable DAW-visible name. Two entries use descriptive names that reflect what the control actually does:

XML nameDAW-visible nameControls
FfdnDriveSaturationAmount of Velvet saturation applied inside the FFDN feedback loop.
FfdnDriveEnabledSaturationEnabledEnable switch for the saturation stage.

12. Troubleshooting

No sound / plugin not passing audio

  • Check that the Bypass switch in the header is off.
  • Check that the Dry fader in MIXER is not at −inf.
  • Check that the input is not being rejected by an aggressive Low Cut or High Cut.

Reverb tail is too short

  • Increase Decay (FFDN) or Decay in LATE DELAY (CloudSeed).
  • Check the SHELVES card: a Bass multiplier well below 1.0× and a Treble multiplier well below 1.0× will shorten the tail at both ends.
  • On CloudSeed, make sure Late Delay is enabled.

Clicks when toggling a Texture layer

This should not happen — all six layers implement anti-click. If you hear one:

  • Check that the Mix knob is not being automated to jump between 0 and a high value instantaneously. Use a short ramp in the host.
  • Make sure no other plugin in the signal chain is producing the click.

Plugin crashes or hangs in the DAW

  • The DSP runs inside a catch-unwind guard, so a panic cannot crash the host — but it can silence the output for one block. If you see intermittent silences, please report a bug with your host and OS version.
  • Make sure your host's plugin sandbox is enabled. If the plugin misbehaves, a sandboxed instance can be killed without taking the host down.

macOS: "Plugin cannot be opened because the developer cannot be verified"

This is standard Gatekeeper behaviour for unsigned binaries. To allow the plugin the first time:

  • Open System Settings → Privacy & Security.
  • Scroll down to the security section. You should see a message about PEJVAK RVB being blocked.
  • Click Open Anyway and confirm.
  • Restart your DAW. The plugin will load normally from then on.

macOS: plugin does not appear in the DAW after installation

  • Confirm you copied the plugin to the correct folder for your DAW (~/Library/Audio/Plug-Ins/VST3/ for user-level or /Library/Audio/Plug-Ins/VST3/ for system-level).
  • Some DAWs (Ableton, Reaper, Bitwig) require you to add the folder to their plugin search path manually.
  • Rescan plugins from the DAW's preferences. On Logic Pro, use Logic Pro → Settings → Plug-in Manager and click Reset & Rescan Selection.

Linux: plugin fails to load with "libGL" or "libX11" errors

Some minimal Linux distributions do not ship the windowing libraries by default. Install them:

sudo apt-get install -y libx11-6 libxcursor1 libgl1 libglu1-mesa

On Fedora / RHEL-based distributions, use dnf with the equivalent package names.

Linux: Wayland vs. X11

The plugin runs under both Wayland and X11. If your DAW uses Wayland and you see rendering glitches, try launching the DAW with XWayland:

GDK_BACKEND=x11 your-daw

Text is too small / too large

Open the ☰ menu, pick Size, and choose a preset from 70 % to 200 %. You can also drag the bottom-right corner of the plugin window to resize it freely; the aspect ratio is locked so the layout never breaks.

Tooltips get in the way

Open the ☰ menu and toggle Show pop-ups off. All hover tooltips will be suppressed until you toggle it back on.

Pejvak DSP — an independent audio plugin studio focused on bit-exact DSP and modern interfaces.
Designed & developed by Amin Yousefinejad.
github.com/Pejvak-DSP

Based on

  • CloudSeed by Valdemar Erlingsson — the original C++ reference. The CloudSeed engine is a faithful f64 port of the legacy-v1 branch and is bit-identical at the sample level.
    github.com/ValdemarOrn/CloudSeed/tree/legacy-v1
  • CloudReverb by xunil-cloud — a JUCE-based fork of CloudSeed that served as a second reference during the port, in particular for cross-platform behaviour and the modern parameter layout.
    github.com/xunil-cloud/CloudReverb
  • FFDN theory: Fagerström et al., "Velvet-Noise Feedback Delay Network" (DAFx 2020); Schlecht & Habets, "Feedback Delay Networks" (IEEE TSP 2017).
  • Velvet-noise diffusion: Välimäki et al. (IEEE/ACM TASLP 2017).
  • Sine-shaper saturation: Zölzer, DAFX.
  • Granular design: Curtis Roads, Microsound (MIT Press, 2001).

Built with

  • Rust 1.98+
  • nice-plug 0.4.2 — plugin framework
  • egui 0.36 — user interface
  • wide 1.6 — portable SIMD
